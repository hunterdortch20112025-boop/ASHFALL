# ASHFALL - Godot 4 starter

## Open
Open `project.godot` with Godot 4.x.

## Controls
- WASD or arrow keys: move
- Mouse: look around
- Left mouse: fire
- Space: jump
- Shift: sprint
- Escape: release mouse
- HUD buttons: drink, eat, save, load, fire, reload

## Important limitations
This is a playable prototype foundation, not a finished game.
The ENet manager only provides host/join connection scaffolding. Player movement,
weapons, enemies, inventory, and world state are NOT yet synchronized between
clients. Reload is a prototype refill, the world is procedural blockout geometry,
and there are no production accounts, dedicated servers, anti-cheat, or APK export
included. Test and fix errors in Godot before attempting an Android export.
